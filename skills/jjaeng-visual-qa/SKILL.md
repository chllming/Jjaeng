# Jjaeng visual QA

Capture a baseline and follow-up image using the same monitor, workspace, or
window target. Preserve both artifact IDs and compare dimensions before making
visual claims. Use OCR only when text comparison is required, and avoid
uploading images to external services without explicit permission.
