# Jjaeng research workflow

Use the host's web search and fetch tools for online research. Preserve source
URLs, publication dates, and claims; distinguish sourced facts from inference.
Jjaeng is not a web-search server. Never upload a screenshot, recording, or
local artifact to a website unless the user explicitly requests that action.
